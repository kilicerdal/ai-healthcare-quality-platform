# Demonstration notes

The included 75-second video is a captioned walkthrough of actual test-report screenshots. It is not a continuous screen recording and contains no voice narration.

## Re-recording a live walkthrough

1. Introduce the project and its scope (0–10 seconds).
2. Run the documented test command and show the real result (10–30 seconds).
3. Open the HTML report and select a representative test (30–50 seconds).
4. Explain its assertions and how retained traces help investigate failures (50–65 seconds).
5. Show the corresponding GitHub Actions run and link to the code (65–75 seconds).

Use synthetic data and public demo targets. Explain any failing or skipped tests accurately. Capture a fresh result before updating the dated sample report.
